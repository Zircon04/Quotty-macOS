# Quotty для macOS

Нативный порт [Quotty](https://github.com/confeden/Quotty) для macOS (SwiftUI + AppKit).

Интерактивный и удобный счётчик квот для **Antigravity**, **Codex** и **Claude** — показывает не только текущий расход лимита, но и темп расхода с белой отметкой времени и пузырьковой анимацией.

Тонкая элегантная полупрозрачная полоска поверх всех окон: отображает остаток квоты и время сброса лимита. Автоматически переключается на инструмент, в котором вы сейчас работаете (включая CLI в Terminal, iTerm2, Alacritty, Warp, Ghostty, VS Code и др.).

---

## Возможности

- **Плавающая полоска поверх всех окон**: не перехватывает фокус, свободно перемещается левой кнопкой мыши в любое удобное место.
- **Поддержка трёх семейств ИИ-инструментов**:
  - **Antigravity** — прямое подключение к локальному языковому серверу Antigravity (отдельные полосы для Gemini и Claude / GPT).
  - **Codex** — чтение токенов из `~/.codex/auth.json` и запрос к ChatGPT rate-limit API.
  - **Claude** — чтение токенов Claude Desktop / CLI и запрос к Anthropic OAuth usage API.
- **Индикация темпа расхода**:
  - **Зеленая полоса** — расход в пределах времени; поднимаются пузырьки с края расхода.
  - **Желтый участок** — перерасход (расход быстрее, чем течет время до сброса).
  - **Оранжевая полоса** — квота полностью исчерпана (100%).
  - **Белая вертикальная риска** — текущая отметка времени окна.
- **Автопереключение по активному окну** (`NSWorkspace` + отслеживание CLI в терминалах).
- **Иконка в macOS Menu Bar (строке меню)**:
  - Быстрое переключение инструмента.
  - Принудительное обновление квот.
  - Показ/скрытие полоски.
  - Открытие настроек.
- **Окно настроек в фирменном темном стиле Quotty**:
  - Слайдер непрозрачности (от 15% до 100%) и пресеты 50%, 80%, 100%.
  - Включение/отключение семейств инструментов.
  - Режим заголовка (Полный, Только имя, Скрыть).
  - Настройка интервала опроса (15 сек, 30 сек, 1 мин, 2 мин, 5 мин).
  - Включение/отключение анимации пузырьков.
- **Энергоэффективность и скорость**:
  - Чистый нативный Swift 6 / SwiftUI (размер бинарника < 1 МБ, RAM ~15-25 МБ, частота до 120 FPS ProMotion без лишней нагрузки на CPU/GPU).
  - Не оставляет иконки в Dock (`LSUIElement = true`).

## Установка и запуск

### Быстрый запуск
Приложение уже собрано в репозитории:
```bash
open Quotty.app
```

Чтобы установить в систему:
```bash
cp -R Quotty.app /Applications/
```

### Сборка из исходников
Для сборки требуется только стандартный компилятор Swift (Xcode Command Line Tools):
```bash
./scripts/build_app.sh
```

---

## Управление

- **ЛКМ по полоске** — перетащить в любое место экрана (позиция автоматически сохраняется).
- **ПКМ по полоске** — контекстное меню (выбор инструмента, непрозрачность, настройки, выход).
- **Клик по иконке в строке меню macOS** — доступ ко всем функциям и переключению.

---

## Конфигурация
Настройки сохраняются в формате JSON:
`~/Library/Application Support/Quotty/settings.json`
